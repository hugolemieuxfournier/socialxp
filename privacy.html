Privacy policy

Last updated: November 8, 2026.

socialxp is a personal tool. Its only user is the owner of the YouTube channels it reads.

  • Data accessed: read-only YouTube Data API and YouTube Analytics API data for the owner's own channels.
  • Use: displayed on a private dashboard on the owner's local network. Nothing is sold, shared or used for advertising.
  • Storage: OAuth tokens and statistics are stored only on the owner's own computer.
  • Revocation: access can be removed at any time at myaccount.google.com/permissions.

socialxp's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube API Services are used under the YouTube Terms of Service and the Google Privacy Policy.
